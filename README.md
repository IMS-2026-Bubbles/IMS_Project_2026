# IMS_Project

## Guidelines for Bubbles

### Development branch
This is the branch that we work with. 

Before pushing anything, make sure you have done this:
- Commented the code so that it is understandable
- Don't replace existing and working code with code that does not work
- Write a clear commit comment and description on what you have done
- If parts of your code does not work, CLARIFY this with extra comments and also in the commit description
- Update the Kanban accordingly
- Don't copy code from AI

Remember to push your code often so that others can be updated.
Remember to pull so that you have the newest version.


### Main branch
This is just for completely working version. The group decides to merge the "development" branch to the main branch on meetings.
